**Random Bot** — игровой Telegram-бот на Python и **pyTelegramBotAPI**. Здесь есть мини-игры, монеты, опыт, коллекция эмодзи, кейсы, праздничные титулы и рынок между игроками.

Зимний сезон посвящён **декабрю 2026 года**, Новому году **2027** и годовщине сообщества **Openbot.Ai**. Общие статусы и глобальные ограничения пользователей работают через **Openbot ID**.

> 🚀 **Премьера зимнего сезона:** 1 декабря 2026 года, **00:00 МСК (UTC+3)**. До открытия игроки видят обратный отсчёт. Новые возможности могут включаться постепенно в следующих патчах.

## 📅 Адвент-календарь декабря

- **1–31 декабря 2026 года:** каждый день открывается новый подарок.
- Пропущенные дни **не сгорают** — награды можно забрать позднее.
- Можно получить один подарок или нажать **«🎁 Забрать всё доступное»**.
- Результат получения отображается во всплывающем уведомлении Telegram.
- Один и тот же подарок нельзя получить повторно.
- **31 декабря:** особый подарок с титулом **«🎆 Новый год 2027»**.
- Время открытия дней рассчитывается по **МСК (UTC+3)**.

Открыть календарь: `/calendar`.

## ❄️ Зимняя лавка и снежинки

**Снежинки** — отдельная валюта зимнего события. Их можно зарабатывать в играх, получать в календаре и в других праздничных наградах.

В **«🎁 Зимней лавке»** доступны два раздела:

1. **❄️ Купить за снежинки** — праздничные титулы и зимние награды.
2. **🛒 Обычный магазин** — кейсы, другие титулы и раздел покупок за Telegram Stars.

Часть титулов выдаётся за события и не требует покупки. Уже полученные титулы сохраняются в коллекции **«🏆 Мои титулы»**.

## 📦 Кейсы и коллекция эмодзи

В боте есть восемь типов кейсов: деревянный, серебряный, золотой, алмазный, огненный, космический, королевский и кейс Пустоты.

Кейсы могут содержать **монеты, XP, снежинки и эмодзи**. Собранные эмодзи можно просмотреть в инвентаре, установить в профиль, продать или выставить на рынок.

## 🎄 Новогодняя ярмарка

Игроки могут выставлять свои эмодзи на продажу за монеты и покупать лоты других участников. В ярмарке отображаются **эмодзи, редкость, цена и продавец**.

- 🛒 Покупка эмодзи у другого игрока.
- 📦 Просмотр своих лотов.
- ❌ Снятие собственного лота с продажи.
- 🔄 Обновление списка и переключение страниц.
- 🔔 Уведомление продавцу об успешной продаже, если уведомления включены.

Для продажи из чата также доступна команда `/sell_emoji ЭМОДЗИ ЦЕНА`.

## 👤 Профиль и Openbot ID

Профиль содержит уровень, опыт, монеты, снежинки, титул и персональные настройки. **Openbot ID** объединяет роли и данные пользователя между ботами сети Openbot.Ai.

В интерфейсе используются **Inline-кнопки** и **Reply-клавиатура**. При временной технической проблеме Reply бот может рекомендовать перейти на Inline. Управление ограничениями — у администрации.

## ⭐ Telegram Stars

В боте предусмотрен магазин цифровых игровых товаров за Telegram Stars: монеты, снежинки и повышение игрового уровня. Доступность покупок зависит от состояния магазина и действующих ограничений.

> Команды требуют соответствующих прав. Доступ зависит от роли и уровня в **Openbot ID**.

| `/gift` | Выдать эмодзи пользователю |

### 🚀 Управление релизом

```text
/launch on       — включить экран ожидания
/launch off      — отключить экран ожидания
/launch status   — состояние запуска
/features        — посмотреть этапы открытия игр
/features safe on  — открыть «Ледяной сейф»
/features quiz on  — открыть «Зимние загадки»
```

**Winter Launch** не следует путать с техническим обслуживанием `/tech`: это отдельные режимы.

## 🔐 Права и безопасность

- Роли сети: `owner`, `developer`, `admin`, `tester`, `coder`, `user`; блокировки учитываются отдельно.
- Права на служебные операции проверяются через **Openbot ID**, а не только по кнопкам в интерфейсе.
- Локальные и глобальные баны ограничивают соответствующие действия игрока.
- Настройки, подарки и данные экономических операций сохраняются в SQLite.
- Повторное нажатие кнопки получения календарной награды не должно начислять её ещё раз.
- Токены Telegram и ключи Openbot API **нельзя публиковать в репозитории**. Используйте переменные окружения и не коммитьте секреты.

## 🗂 Структура проекта

```text
random_bot/
├── test.py                   # основной файл текущей тестовой сборки
├── newyear_random_db.py      # зимнее событие, снежинки, кейсы и титулы
├── emoji_data.json           # каталог эмодзи
├── Random_bot.1.6.db         # основная SQLite-база (не коммитить)
└── Newyear_random.db         # база зимнего события (не коммитить)
```

Основная база хранит профили, активные игры, монеты, рынок, настройки, статистику и платежи. В отдельной **`Newyear_random.db`** хранятся данные зимнего события, включая снежинки, праздничные награды и титулы. Глобальный Openbot ID обслуживается отдельно.

> Название основного файла зависит от ветки и способа развёртывания. В тестовой сборке используется `test.py`.

## 🚀 Установка и запуск

```bash
# Получить репозиторий
git clone https://github.com/Kafnik/random_bot.git
cd random_bot

# Создать окружение
python3 -m venv venv
source venv/bin/activate

# Базовые зависимости
pip install pyTelegramBotAPI
# Установи также библиотеку openbot_api из сборки проекта

# Проверка синтаксиса перед запуском
python -m py_compile test.py newyear_random_db.py

# Запуск тестовой сборки (после настройки секретов и зависимостей)
python test.py
```

Для работы требуются корректные настройки Telegram Bot API, Openbot API, доступные зависимости проекта и файлы конфигурации. Название пакета библиотеки Openbot API при установке зависит от того, как он опубликован в вашей среде; при необходимости используйте пакет, поставляемый командой проекта.

**Перед обновлением:** сохраняйте резервные копии основной и зимней SQLite-баз. Обновляйте сначала тестовую ветку/бота, затем основную.
