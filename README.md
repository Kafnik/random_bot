Telegram-бот на Python (**pyTelegramBotAPI**) с экономикой, коллекцией эмодзи, рынком между игроками и хэллоуинским событием **«Рандом-мир»**. Часть сети ботов **Openbot.Ai**: права и баны берутся из общего аккаунта **OpenBot ID**.

---

## ✨ Возможности

### 🎮 Игры
| Игра | Описание |
|---|---|
| 🔐 Взлом замка | угадай код по подсказкам |
| 🗝️ Испытание ключей | мини-игра на удачу |
| 👻 Охота на тень | мини-игра на реакцию |
| 🧪 Ведьмино зелье | мини-игра на удачу |
| 🎃 Тыквенный выбор | мини-игра на удачу |
| ❌⭕ Крестики-нолики | против бота |

Победы приносят монеты, опыт и 🍬 конфеты. Любую игру можно остановить командой `/game_stop`.

### 🍬 Хэллоуин и «Рандом-мир»
- **Конфеты** — валюта события. Выпадают за игры, достижения и подарок дня.
- **Жуткий сундук** — за конфеты выдаёт случайное эмодзи. Дубликат превращается в монеты.
- **Дом с привидениями** — строится и улучшается до 5 уровня, сам копит конфеты (хранилище на 8 часов), забираешь их когда хочешь.
- **Подарок дня** — бесплатные конфеты раз в сутки.
- **События дня** (одно для всех игроков, меняется каждые сутки):
  🏷 Распродажа у призрака (сундук дешевле), 🌕 Полнолуние (дом производит вдвое больше), 🎁 Щедрый призрак (подарок дня ×2).
- **Достижения** с наградами: «Первая победа», «Взломщик замков», «Сладкоежка», «Охотник за сундуками», «Хозяин дома», «Любимчик призрака».
- **Хэллоуинские титулы** — покупаются за монеты, отображаются в профиле.

### 📦 Кейсы
8 кейсов с разными наградами (монеты, XP, эмодзи): 📦 Деревянный, 🥈 Серебряный, 🥇 Золотой, 💎 Алмазный, 🔥 Огненный, 🌌 Космический, 👑 Королевский, 🕳️ Кейс Пустоты. Часть кейсов покупается за монеты, часть — за конфеты.

### 😎 Коллекция эмодзи
- около 200 эмодзи семи редкостей (от «Обычной» до «Легендарной»), у каждой свой цветной кружок;
- инвентарь с постраничным просмотром, карточка эмодзи: надеть на профиль, продать боту, выставить на рынок;
- проданное или выставленное на рынок последнее эмодзи автоматически снимается с профиля.

### 🏪 Рынок (аукцион)
Игроки продают друг другу эмодзи за монеты. Свой лот можно снять, продавцу приходит уведомление о продаже. Команда `/sell_emoji [эмодзи] [цена]` выставляет лот прямо из чата.

### 👤 Профиль и OpenBot ID
- профиль с уровнем, XP, монетами, титулом и надетым эмодзи;
- глобальный аккаунт `/id_profile` с био (`/bio`), статусом и списком ботов сети;
- два режима интерфейса на выбор: **inline-кнопки** или **reply-клавиатура** (переключается в настройках).

### ⭐ Telegram Stars
Покупка за Stars: монеты, конфеты, прокачка уровня. Возврат платежа — команда `/refund` (для разработчиков).

## 🤖 Команды

**Для всех**

| Команда | Что делает |
|---|---|
| `/start` | запуск бота |
| `/help` | список команд |
| `/profile` | профиль игрока |
| `/sell_emoji` | выставить эмодзи на рынок |
| `/game_stop` | остановить текущую игру |
| `/id_profile` | глобальный аккаунт OpenBot ID |
| `/bio` | изменить био в глобальном аккаунте |
| `/feedback` | отправить отзыв разработчикам |

**Для команды (developer / tester / admin / owner)**

| Команда | Что делает |
|---|---|
| `/ban`, `/unban` | бан и разбан в этом боте |
| `/id_ban`, `/id_unban` | глобальный бан и разбан ID |
| `/id_freeze`, `/id_unfreeze` | заморозка и разморозка ID |
| `/give_coins`, `/take_coins` | выдать и забрать монеты |
| `/gift` | подарить эмодзи игроку |
| `/level_up` | изменить уровень игрока |
| `/sendall` | рассылка всем игрокам |
| `/MODE_true`, `/MODE_false` | включить и выключить тех. обслуживание |
| `/refund` | вернуть платёж в Stars |

## 🔐 Права и безопасность

- Статусы: `owner` · `developer` · `admin` · `moderator` · `tester` · `user` · `frozen` · `banned`.
- Права проверяются локально через модуль `openbot_id` (функция `check_access(user_id, статусы, уровень)`), без обращений к внешнему API.
- **Тех. обслуживание**: флаг `maintenance` хранится в базе (`0` / `1`). Пока он включён, бот отвечает только команде, остальным показывает «Ведутся технические работы». Проверка стоит в одном месте (middleware), в каждый обработчик её добавлять не нужно.
- Глобально забаненные и замороженные аккаунты не могут пользоваться ботом.
- Ошибки бота (traceback) приходят в чат разработчика (`DEVELOPER_CHAT_ID`).

## 🗂 Структура проекта

```
random_bot/
├── Random_bot.1.6.py          # основной код бота
├── openbot_id.py              # общий аккаунт и права (OpenBot ID)
└── halloween_random_db.py     # отдельная база хэллоуинского события
```

Базы создаются автоматически при первом запуске:

| Файл | Что хранит |
|---|---|
| `Random_bot.1.6.db` | игроки, инвентарь эмодзи, рынок, дом, статистика, достижения, платежи |
| `Halloween_random.db` | конфеты, кейсы игроков, купленные титулы, журнал событий |
| `openbot_id.db` | глобальные аккаунты сети |

**Отдельная база события.** Все изменения в `Halloween_random.db` проходят только через `halloween_random_db.py`: потокобезопасно, атомарно, с журналом (кто, когда, что и на сколько изменил). При первом запуске модуль один раз переносит старые данные из основной базы (основная база только читается, повторный перенос ничего не дублирует).

## 🚀 Установка и запуск

Скачиваем с Releses или вот так

```bash
git clone https://github.com/Kafnik/random_bot
cd random_bot
pip install pyTelegramBotAPI
python Random_bot.1.6.py
```

Перед запуском в `Random_bot.1.6.py` задай:
- `TOKEN` — токен бота от [@BotFather](https://t.me/BotFather);
- `DEVELOPER_CHAT_ID` — твой Telegram ID (сюда приходят отзывы и логи ошибок).

Требования: Python 3.9+, `pyTelegramBotAPI`.

## 🌐 Сеть Openbot.Ai

Random Bot работает вместе с **Master Bot**: общий аккаунт OpenBot ID, общие статусы и глобальные баны. У каждого бота своя основная база и своя база хэллоуинского события, поэтому они не конфликтуют.
